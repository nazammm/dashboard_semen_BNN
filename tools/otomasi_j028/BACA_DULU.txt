NAZAM AUTO TASK
================
Aplikasi untuk mengambil data ERP (J028 + J028B, J073, Sub ERP, ongkos kirim J073 + ORDB019), TIRO (Sell In, Outstanding DO), dan
rekap DO harian di folder korin (DO FAS), file Stock Semen bulan berjalan di folder b236 (Stock), lalu memasukkannya ke SEMENTRACK. Rentang ERP: tanggal 1 bulan ini s.d. hari ini; TIRO: 1 Januari s.d. hari ini.

TIRO butuh captcha: klik Login TIRO, ketik kodenya di jendela yang terbuka. Sesi disimpan dan dipakai
lagi sampai habis; kalau habis saat jadwal jalan, jendela login terbuka sendiri dan menunggu 10 menit.

Membuat aplikasinya (sekali saja)
1. Klik dua kali buat_exe.bat, tunggu sampai selesai (1-3 menit).
2. Ambil dist\Nazam Auto Task.exe, pindahkan ke folder tetap, mis. Documents\Nazam Auto Task.
3. Buka exe itu. Pengaturan, riwayat, dan folder unduhan dibuat di folder yang sama.

Pertama kali dibuka
1. Pengaturan: isi akun ERP dan SEMENTRACK, klik Simpan, lalu Uji login.
2. Beranda: centang "Hanya pratinjau", klik Jalankan. Kalau semua hijau/kuning tanpa merah,
   jalankan lagi tanpa "Hanya pratinjau".
3. Jadwal: Pengaturan -> Jadwal otomatis (selama aplikasi terbuka), atau "Daftarkan ke Windows"
   supaya tetap jalan walau aplikasi ditutup. Pilih salah satu saja.

Tanpa aplikasi (baris perintah) tetap bisa: python j028_harian.py --semua (lihat keterangan di atas file itu).

Ongkos kirim (halaman Ongkos Kirim di SEMENTRACK)
- Centang "Ongkos kirim" di Beranda (dan ikut jadwal). Dari jadwal bagian ini hanya jalan seminggu sekali.
- Tiap distributor di Pengaturan -> Distributor ongkos: J073 3 bulan terakhir (satu job) dan laporan ORDB019
  bulan lalu + bulan ini (satu laporan per bulan). INSA-E tidak perlu: datanya ada di INSA (4094).
- Antrian ERP paling banyak 2 job/laporan sekaligus; sisanya dikirim begitu ada yang selesai.
- Data lama: Pengaturan -> "Isi data lama sejak" 2025-01 -> Isi ulang ongkos. Dikerjakan per 8 job/laporan
  (unduh lalu langsung upload) dan dicatat di isi_ulang_ongkos.json. Kalau terhenti, klik lagi; yang sudah
  masuk dilewati. Hapus file itu kalau ingin mengulang semuanya dari awal.
- Rentang tertentu (paling panjang 3 bulan): Pengaturan -> Ambil rentang, mis. 2025-08-01 s.d. 2025-10-31,
  Distributor kosong = semua, atau isi beberapa kode (9575,4403). Tidak mengubah jadwal mingguan.
- Sebelum meminta ORDB019, View Report diperiksa dulu (sampai 10 halaman): laporan distributor + periode yang sudah ada
  dan FINISHED langsung diunduh. Bulan ini dan bulan lalu hanya dipakai kalau laporannya dibuat hari ini.
- Isi ulang dikerjakan per bulan untuk ke-13 distributor bersamaan (bukan satu distributor sampai habis dulu).
- Submit gagal dicoba lagi tiap 1 menit (3x). Sudah submit tapi belum muncul di View Report / View Job: dicek tiap
  menit; 10 menit belum muncul, submit ulang (3x).
- Baris perintah: python j028_harian.py --bagian ONGKOS    atau    --bagian ONGKOS --isi-ulang 2025-01
  atau    --ongkos-dari 2025-08-01 --ongkos-sampai 2025-10-31 --ongkos-dist 9575
